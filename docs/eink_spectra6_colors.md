# E Ink Spectra 6 颜色参考

本文档记录 M5Stack PaperColor 所使用的 **E Ink Spectra 6** 六色电子墨水屏的颜色特性与推荐取值，供 UI 设计、代码开发和预览模拟参考。

---

## 技术概述

E Ink Spectra 6 采用 **颜料级六色** 技术，屏幕内部物理封装了 6 种带电颜料微胶囊：

- **黑 (Black)**、**白 (White)**
- **红 (Red)**、**黄 (Yellow)**
- **蓝 (Blue)**、**绿 (Green)**

> ⚠️ **重要**：这不是 LCD/OLED 的 RGB 子像素混合发光，而是 6 种离散颜料的物理排列与反射。屏幕**无法显示全色域**，任何输入的 RGB 值都会被驱动芯片量化映射到最接近的颜料色。因此：
>
> - 禁止渐变、半透明、复杂混色
> - 不要假设 RGB 中间值会有平滑过渡
> - 设计时只使用这 6 种纯色 + 黑白

---

## 推荐颜色值

### 设计预览 / Web 模拟用（24-bit RGB）

以下值经过调整，更接近真实墨水在纸张上的实际反射视觉效果，适用于设计稿、Web 端预览、截图模拟：

| 墨水颜色 | Hex | RGBA | 视觉特征 |
|---------|-----|------|---------|
| **黑** | `#000000` | `rgba(0, 0, 0, 1)` | 纯黑，吸收率高 |
| **白** | `#FFFFFF` | `rgba(255, 255, 255, 1)` | 纸张底色，高反射 |
| **红** | `#E60012` | `rgba(230, 0, 18, 1)` | 朱红，比标准正红略沉，接近真实颜料 |
| **黄** | `#FFD700` | `rgba(255, 215, 0, 1)` | 金黄/橙黄，Spectra 6 的黄偏暖 |
| **蓝** | `#0047AB` | `rgba(0, 71, 171, 1)` | 钴蓝/深蓝，偏冷偏暗 |
| **绿** | `#32CD32` | `rgba(50, 205, 50, 1)` | 黄绿/草绿，Spectra 6 的绿明显偏黄 |

### 为什么不用标准 RGB 原色？

| 对比 | 标准 RGB 原色 | Spectra 6 实际颜料 |
|-----|-------------|------------------|
| 绿 | `#00FF00` 纯绿 | 实际偏黄，类似草绿 |
| 黄 | `#FFFF00` 柠檬黄 | 实际偏橙，类似金黄 |
| 红 | `#FF0000` 正红 | 接近，但略沉 |
| 蓝 | `#0000FF` 纯蓝 | 实际偏深，类似钴蓝 |

标准 RGB 原色在设计稿上看起来会**过于鲜艳**，与实体屏幕观感有偏差。使用上表调整后的值，预览效果更真实。

## 代码中使用（16-bit RGB565）

在 Arduino / PlatformIO 环境下，通过 `M5.Display` 或 `M5GFX` 绘图时，驱动层会自动将 RGB 值量化到 6 色颜料。通常直接使用库定义的颜色常量：

```cpp
#include <M5GFX.h>

// 16-bit RGB565 标准定义
#define COLOR_BLACK   0x0000  // #000000
#define COLOR_WHITE   0xFFFF  // #FFFFFF
#define COLOR_RED     0xF800  // #FF0000
#define COLOR_YELLOW  0xFFE0  // #FFFF00
#define COLOR_BLUE    0x001F  // #0000FF
#define COLOR_GREEN   0x07E0  // #00FF00
```

### 量化行为示例

```cpp
// 以下中间色都会被映射到 6 种颜料之一，不会显示为"过渡色"
display.fillRect(0, 0, 100, 100, 0xFC10);  // 偏橙红 → 实际显示为 RED 或 YELLOW
display.fillRect(0, 0, 100, 100, 0x0410);  // 偏青绿 → 实际显示为 GREEN 或 BLUE
```

> 💡 提示：如果项目中有设计预览页面（如 Web 配置端），建议用本文档"设计预览"表格中的 RGB 值渲染色卡，而非直接用 `#FF0000` 等标准原色，以更接近用户最终看到的实体效果。

## 设计约束速查

| 约束 | 说明 |
|-----|------|
| ❌ 禁止渐变 | 屏幕无中间色，渐变会呈现为色带 |
| ❌ 禁止半透明 | Alpha 混合无法实现，只会量化到单一颜料 |
| ❌ 禁止动画 | 刷新伴随全屏闪烁，频繁重绘体验极差且加速屏幕老化 |
| ✅ 推荐风格 | 大色块、高对比、扁平化、边界清晰的图标和文字 |
| ✅ 最佳实践 | "一次刷好、长期保持"，配合深度睡眠实现零功耗静态显示 |
